# 유치부 성구암송 웹앱

판교 사랑의교회 유치부 · 만 3~6세용 성구암송 앱. 기획서: [성구암송앱_기획서_v2.md](성구암송앱_기획서_v2.md)

**주소: https://chloe-jy-74.github.io/bible-memory-kids/**

학부모에게는 이 링크만 보내면 됩니다. 설치 없이 열리고, 폰 브라우저에서
'홈 화면에 추가'를 하면 앱처럼 아이콘이 생깁니다.

## 실행

ES 모듈과 JSON을 쓰기 때문에 파일을 더블클릭하면 안 되고, 간단한 서버가 필요합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

배포는 GitHub Pages / Netlify에 폴더째 올리면 됩니다. 빌드 과정 없음.

## 화면

```
메인 메뉴
├── 📖 구절 듣기   1~12월 (안내 말 없이 조용히) → 녹음 낭독, 멈출 때까지 반복
├── ❓ 월별 퀴즈   1~12월 → 글자 3지선다
├── 🎲 랜덤 퀴즈   월별 문항 51개 전체에서 10문제를 매번 새로 섞어 뽑음
└── ⚙️ 설정        읽어주는 목소리 · 속도 · 톤 · 노란 칸 타이밍 · 진도 초기화
```

## ★ 목소리 — 모든 말이 미리 녹음된 파일입니다

이 앱은 브라우저 TTS로 말하지 않습니다. 구절·문항·선택지·안내가 전부
**같은 사람 목소리(ElevenLabs `Faye`)로 미리 만들어 둔 MP3**입니다.
기기마다 목소리가 달라지지도, 로봇처럼 들리지도 않습니다.

| | 개수 | 위치 |
|---|---|---|
| 구절 낭독 | 12개 | `assets/audio/01.mp3` ~ `12.mp3` |
| 문항·선택지·칭찬·안내 | 191개 | `assets/audio/quiz/` |

동작 방식은 접점이 딱 한 군데입니다 — `js/app.js`의 `setAudioResolver(findClip)`.
`speak('지혜')`가 불리면 [data/audio-index.json](data/audio-index.json)에서 그 **문장 그대로** 찾아
파일이 있으면 재생하고, 없으면 브라우저 TTS로 넘어갑니다. 나머지 코드는 음원의 존재를 모릅니다.

### 문장을 고치거나 추가할 때

문장을 한 글자라도 바꾸면 그 문장은 음원을 못 찾아 **로봇 목소리로 나옵니다.**
같은 목소리로 새로 뽑아서 색인에 넣어야 합니다.

```
엔진   ElevenLabs (Higgsfield 경유), model text2speech_v2 / variant elevenlabs
보이스 Faye · preset · d198dc0b-c4e5-5198-aa1d-ecf5ca0927c4
대본   낱말 하나짜리 선택지는 끝이 흐려지므로 마침표를 붙여서 생성 ("지혜.")
파일명 문장의 SHA1 앞 10자 + .mp3   (같은 문장은 파일 하나를 공유)
```

지금 어떤 문장에 음원이 없는지 확인:

```bash
python3 - <<'PY'
import json, re, glob
idx = json.load(open('data/audio-index.json', encoding='utf-8'))['clips']
q = json.load(open('data/questions.json', encoding='utf-8'))
need = set()
for x in q['monthly'] + q['general']:
    need.add(x.get('speech') or x['display']); need.update(x['choices'])
src = ''.join(open(p, encoding='utf-8').read() for p in glob.glob('js/*.js'))
need |= set(re.findall(r"speak\('([^']+)'\)", src))
print('음원 없는 문장:', sorted(t for t in need if t not in idx) or '없음')
PY
```

## 구절 낭독과 소절 강조

음원 한 개에 **"○월 말씀 → 본문 → 출처"**가 이어져 있습니다.
화면의 소절에 불을 켜기 위해 `data/verses.json`이 이런 값을 들고 있습니다.

```json
"audio": "audio/02.mp3",
"audioSeconds": 11.2,
"cues": [[0.1304, 0.2402], [0.2848, 0.4295], ...],   // 소절별 [시작, 끝]
"refAt": 0.8804                                       // 출처를 읽기 시작하는 지점
```

전부 **음원 길이 대비 비율**입니다. 재생 위치를 보고 지금 읽는 소절을 강조하고,
`refAt`을 지나면 출처에 불을 켭니다. `cues`가 `null`이면 소절 수로 균등 분할합니다.

이 값은 **글자수로 추정하지 않고 파형에서 직접 잰 것**입니다.
글자수 모델은 쉬는 시간을 실제보다 길게 잡아 강조가 최대 1.8초까지 늦었습니다.
지금은 소리가 나는 구간만 골라내어, 글자를 '실제 말하는 시간'에만 배분하고
쉬는 구간은 건너뜁니다. 음원을 새로 녹음하면 아래 방법으로 다시 재야 합니다.

```bash
# ffmpeg 로 10ms 마다 음량을 재서 발화 구간을 찾고, 그 안에 소절을 배분합니다.
# (계산 스크립트는 이 커밋의 대화 기록에 있습니다 — 필요하면 다시 만들어 쓰세요)
ffmpeg -i assets/audio/02.mp3 -ac 1 -ar 16000 /tmp/02.wav
```

> 6월은 엔진이 '곧'을 '귓'으로 읽어서 **녹음 대본에만** '곤'으로 적었습니다.
> 화면에는 반드시 원문 '곧'이 나가야 합니다 (`lines`에 그렇게 들어 있음).

## 값 조정하는 곳

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 반복 간격, 정답 후 대기 등 모든 타이밍 | `js/config.js` → `timing` |
| 정답 칭찬 / 오답 안내 문구 | `js/config.js` → `correctVoice`, `wrongVoice` (바꾸면 음원도 새로 뽑아야 함) |
| 랜덤 퀴즈 한 세트 문항 수 (기본 10) | `js/config.js` → `quiz.randomSetSize` |
| 버튼 높이·글자 크기·색 | `css/style.css` 맨 위 `:root` |
| 구절 내용, 끊어 읽기 위치 | `data/verses.json` |
| 문제·선택지 | `data/questions.json` |

`js/config.js`의 `speech`(속도·톤·음성 목록)는 **음원이 없는 문장에만** 영향을 줍니다.
지금은 모든 문장에 음원이 있으므로 사실상 예비 설정입니다.

## 문항 데이터 쓰는 법

```json
{
  "id": "m08-q4",
  "month": 8,
  "display": "8월말씀. 하나님이 세상을 이처럼 어떻게 하셨나요?",
  "choices": ["이처럼 사랑하사", "이처럼 창조하사", "항상 바라보사"],
  "answer": 0
}
```

- `answer`는 **항상 0** (정답을 맨 앞에). 화면에서는 매번 자동으로 섞입니다.
- **월별 퀴즈와 랜덤 퀴즈는 같은 문항을 씁니다.** 여기에 문항을 넣으면 양쪽에 다 나옵니다.
  (별도의 종합 문제은행은 없습니다 — 예전 `general` 17문항은 뺐습니다.)
- `speech`를 넣으면 화면 글자 대신 그걸 읽습니다 (따옴표·기호가 든 문항에 씁니다).
- 선택지는 **글자만** 나옵니다. 문항도 선택지도 눌러서 소리로 들을 수 있으므로
  글을 모르는 아이도 풀 수 있습니다.

## 앱이 멈추지 않게 해둔 부분

| 상황 | 처리 |
|---|---|
| 음원 파일이 없거나 재생 실패 | 조용히 브라우저 TTS로 되돌아감 |
| 한국어 음성도 없는 기기 | 안내 문구 표시 + 읽는 시간만큼 기다리며 화면은 정상 진행 |
| 브라우저가 재생 끝을 안 알려줌 | 예상 재생시간의 2배가 지나면 다음 단계로 |
| 화면을 나가거나 뒤로 감 | 반복 낭독·대기가 즉시 취소됨 (`stopSpeaking()`) |
| localStorage 사용 불가 | 진도만 저장이 안 되고 앱은 그대로 동작 |

## 원칙

- 한 화면의 버튼은 적게, 크게 (최소 높이 88px, 글자 24px 이상).
- 구절 듣기는 **말씀과 출처만** — 안내·감상 같은 군더더기 말을 넣지 않습니다.
- 정답에는 **칭찬 한 마디만** — 스티커·그림 같은 보상 연출은 넣지 않습니다.
- 오답에도 연출을 넣지 않습니다 (일부러 틀려보게 됩니다). 부드러운 안내 한 마디만.
- 랭킹·점수·제한시간·발음 채점은 넣지 않습니다 (기획서 9장).
