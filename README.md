# 유치부 성구암송 웹앱

판교 사랑의교회 유치부 · 만 3~6세용 성구암송 앱. 기획서: [성구암송앱_기획서_v2.md](성구암송앱_기획서_v2.md)

## 실행

ES 모듈과 JSON을 쓰기 때문에 파일을 더블클릭하면 안 되고, 간단한 서버가 필요합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

배포는 GitHub Pages / Netlify에 폴더째 올리면 됩니다. 빌드 과정 없음.
(마이크를 쓰는 '따라 읽기' 때문에 HTTPS 필수 — 위 두 곳은 기본 HTTPS입니다.)

## 화면

```
이름 입력(첫 실행 한 번) → 메인 메뉴
├── 📖 구절 듣기   1~12월 → 자동 낭독, 읽는 소절 강조
├── 🗣️ 따라 읽기   1~12월 → 소절 무한 반복 (따라 하기 / 이어 말하기)
├── ❓ 월별 퀴즈   1~12월 → 3지선다, 완주하면 도감에 동물 수집
├── 🎲 랜덤 퀴즈   10문제 (이번 달 50% + 이전에 배운 달 50%)
├── 🐾 동물 도감   12마리 수집 현황
└── ⚙️ 설정        아이 이름 · 지금 배우는 달 · 따라 읽기 방식 · 진도 초기화
```

## 폴더 구조

```
index.html
css/style.css        화면 크기·색상 설정이 맨 위 :root 에 모여 있음
js/config.js         ★ 타임아웃 8초, 보상 1.5초 같은 동작 숫자는 전부 여기
js/speech.js         ★ speak(text) 한 곳만 갈아끼우면 TTS ↔ 음성파일 전환
js/mic.js            마이크 (소리가 났는지만 판단, 발음 채점 없음)
js/data.js           구절·문항·그림 로딩
js/questions.js      선택지 섞기, 그림 연결, 랜덤 세트 구성
js/storage.js        진도 저장 (localStorage)
js/router.js         화면 전환 (뒤로가기·안드로이드 백버튼)
js/screens.js        모든 화면
js/app.js            시작점
data/verses.json     12개 구절 + 끊어 읽기 소절
data/questions.json  월별 74문항 + 종합 17문항
assets/              그림 71장 + images.json
```

## 값 조정하는 곳

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 무음 대기 8초, 정답 보상 1.5초, 자동 진행 3초 등 모든 타이밍 | `js/config.js` → `timing` |
| 말하는 속도(rate 0.85), 언어 | `js/config.js` → `speech` |
| 마이크 감도 (너무 예민하거나 둔하면) | `js/config.js` → `mic.rmsThreshold` |
| 칭찬 / 오답 음성 문구 | `js/config.js` → `praise`, `repeatPraise`, `wrongVoice` |
| 랜덤 퀴즈 문항 수, 이번 달 비율 | `js/config.js` → `quiz` |
| 버튼 높이·글자 크기·색 | `css/style.css` 맨 위 `:root` |
| 구절 내용, 끊어 읽기 위치 | `data/verses.json` (코드 수정 불필요) |
| 문제·선택지 | `data/questions.json` (코드 수정 불필요) |

## 문항 데이터 쓰는 법

```json
{
  "id": "m08-q4",
  "month": 8,
  "display": "하나님이 세상을 이처럼 ○○하사",
  "speech": "하나님이 세상을 이처럼 어떻게 하셨나요?",
  "choices": ["사랑", "미워", "걱정"],
  "answer": 0
}
```

- `answer`는 **항상 0** (정답을 맨 앞에). 화면에서는 매번 자동으로 섞입니다.
- `speech`가 없으면 `display`를 그대로 읽습니다. `○○` 같은 빈칸 문항에는 꼭 넣어 주세요.
- 선택지 그림은 `assets/images.json`의 한글 라벨로 **자동 연결**됩니다.
  셋 다 그림이 있으면 그림 3지선다, 하나라도 없으면 글자 3지선다가 됩니다.
- 뜻이 헷갈리는 그림이 붙을 때는 `"noImage": true`로 글자만 쓰게 합니다.
  (예: '보라 ○ 것이 되었도다'의 '새' → 새(bird) 그림이 붙으면 안 됨)

## 음성 교체 방법

지금은 브라우저 내장 TTS입니다. 나중에 음성파일이나 부모 녹음으로 바꿀 때는
`js/speech.js`의 `setAudioResolver()` 한 줄만 등록하면 되고, 나머지 코드는 그대로입니다.

```js
import { setAudioResolver } from './speech.js';
setAudioResolver(text => AUDIO_MAP[text] || null);   // 없는 문장은 자동으로 TTS
```

파일이 없거나 재생에 실패하면 조용히 TTS로 되돌아갑니다.

## 앱이 멈추지 않게 해둔 부분

| 상황 | 처리 |
|---|---|
| 마이크 권한 거부 | 자동 진행 모드 (소절 재생 후 3초 대기 → 다음). 상단에 '자동 진행' 표시 |
| 권한 창을 안 누르고 둠 | 6초 뒤 자동 진행으로 시작. 나중에 허용하면 그때부터 마이크 사용 |
| 8초간 무음 | 실패 처리 없이 조용히 다음 소절로 |
| 한국어 음성이 없는 기기 | 안내 문구 표시 + 읽는 시간만큼 기다리며 화면은 정상 진행 |
| 브라우저가 재생 끝을 안 알려줌 | 예상 재생시간의 2배가 지나면 다음 단계로 |
| localStorage 사용 불가 | 진도만 저장이 안 되고 앱은 그대로 동작 |

## 원칙

- 그림에 한글 라벨이 이미 인쇄되어 있으므로 **화면에 라벨을 다시 쓰지 않습니다.**
- 한 화면의 버튼은 적게, 크게 (최소 높이 88px, 글자 24px 이상).
- 오답에는 연출을 넣지 않습니다 (일부러 틀려보게 됩니다).
- 랭킹·점수·제한시간·발음 채점은 넣지 않습니다 (기획서 9장).
